Implemented

crawl
- Crawl the entire steam page
- go run steam-price-tracker crawl 

deals
- Display games currently discounted
- go run steam-price-tracker deals <flag> <value>

display
- Print the 1st 10 game price data
- Allow pagination
- go run steam-price-tracker display <page number>

history
- Display a game's price history
- go run steam-price-tracker history <app id | title>

lowest
- Display lowest recorded price for a game
- go run steam-price-tracker lowest <app id | title>

search
- Find a game matching the prefix string
- go run steam-price tracker search <prefix string>

update
- Update a game
- go run steam-price-tracker update <app id | title>

stats
- Display tracker statistics
- go run steam-price-tracker stats

Not Implemented

track
- Track a game
- Display a game's price data as trend graph
- go run steam-price-tracker track <app id | title>
